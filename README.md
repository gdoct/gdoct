Hi, I'm Guido 👋

I build software for fun — mostly to see how far an idea (or a language model) can be pushed. Some of these projects are polished, some are experiments that stopped once the question was answered.

### Featured projects
* [**vibeos**](https://github.com/gdoct/vibeos) — A from-scratch x86-64 operating system with a UEFI bootloader, an SMP kernel, a writable filesystem, a real TCP/IP stack, and a userspace GUI — built almost entirely by AI models under close supervision in about a week, as an experiment in how far that approach could go.

* [**apexsim**](https://github.com/gdoct/apexsim) — An open-source simracing platform: a Rust server running an authoritative 240Hz physics simulation paired with a Godot client, with measured track data and car physics.

* [**ai-storywriter**](https://github.com/gdoct/ai-storywriter) — A visual, canvas-based story writer where you arrange characters, world, and plot beats as connected nodes, then have an AI agent turn the board into a streamed story.

* [**iptv-webplayer**](https://github.com/gdoct/iptv-webplayer) — A privacy-first, single-file IPTV player that streams MPEG-TS channels entirely client-side, no telemetry, no server dependency.

### What I'm into
Systems programming, simulation, and seeing what AI-assisted software engineering can actually build when pushed.
